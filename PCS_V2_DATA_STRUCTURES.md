# PCS V2 Data Structures Documentation

## Overview

PCS V2 defines comprehensive data structures in SystemCore.bas that represent all business entities, provide type safety, and enable structured data flow throughout the system. All structures maintain complete compatibility with the original Excel file formats while providing cleaner programmatic access.

## Core Data Types

### **EnquiryData Structure**

**Purpose**: Complete enquiry information for customer requests

```vba
Public Type EnquiryData
    EnquiryNumber As String           ' E00001 format, auto-generated
    CustomerName As String            ' Business identification
    ContactPerson As String           ' Primary contact at customer
    CompanyPhone As String            ' Customer phone number
    CompanyFax As String              ' Customer fax (legacy compatibility)
    Email As String                   ' Customer email address
    ComponentDescription As String    ' Part description
    ComponentCode As String           ' Internal part code
    MaterialGrade As String           ' Material specification
    Quantity As Long                  ' Required quantity (must be > 0)
    DateCreated As Date              ' Enquiry creation timestamp
    FilePath As String               ' Full path to enquiry Excel file
    SearchKeywords As String         ' Composite search terms
End Type
```

**Field Dependencies**:
- **EnquiryNumber**: Generated by `DataOperations.GetNextEnquiryNumber()`
- **FilePath**: Created by `DataOperations` file operations
- **SearchKeywords**: Composite of CustomerName + ComponentDescription + ComponentCode

**Business Rules**:
- CustomerName and ComponentDescription are required fields
- Quantity must be > 0
- DateCreated auto-set to current timestamp
- EnquiryNumber follows E00001, E00002, etc. sequence

**Excel File Mapping** (Admin Sheet):
```
Cell B2  → EnquiryNumber
Cell B3  → CustomerName
Cell B4  → ContactPerson
Cell B5  → CompanyPhone
Cell B6  → CompanyFax
Cell B7  → Email
Cell B8  → ComponentDescription
Cell B9  → ComponentCode
Cell B10 → MaterialGrade
Cell B11 → Quantity
Cell B12 → DateCreated
```

### **QuoteData Structure**

**Purpose**: Quote information with pricing and delivery terms

```vba
Public Type QuoteData
    QuoteNumber As String             ' Q00001 format, auto-generated
    EnquiryNumber As String           ' Reference to source enquiry
    CustomerName As String            ' Inherited from enquiry
    ComponentDescription As String    ' Inherited from enquiry
    ComponentCode As String           ' Inherited from enquiry
    MaterialGrade As String           ' Inherited from enquiry
    Quantity As Long                  ' Inherited from enquiry
    UnitPrice As Currency            ' Price per unit (must be > 0)
    TotalPrice As Currency           ' UnitPrice * Quantity
    LeadTime As String               ' Manufacturing lead time description
    ValidUntil As Date               ' Quote expiration date
    DateCreated As Date              ' Quote creation timestamp
    FilePath As String               ' Full path to quote Excel file
    Status As String                 ' "Pending", "Accepted", "Rejected"
End Type
```

**Inheritance Pattern**:
```vba
' Data inherited from EnquiryData
QuoteInfo.EnquiryNumber = EnquiryInfo.EnquiryNumber
QuoteInfo.CustomerName = EnquiryInfo.CustomerName
QuoteInfo.ComponentDescription = EnquiryInfo.ComponentDescription
QuoteInfo.ComponentCode = EnquiryInfo.ComponentCode
QuoteInfo.MaterialGrade = EnquiryInfo.MaterialGrade
QuoteInfo.Quantity = EnquiryInfo.Quantity
```

**Business Rules**:
- Must reference valid EnquiryData record
- UnitPrice must be > 0
- TotalPrice automatically calculated (UnitPrice × Quantity)
- ValidUntil defaults to DateCreated + 30 days
- Status tracked throughout workflow

**Price Calculations**:
```vba
QuoteInfo.TotalPrice = QuoteInfo.UnitPrice * QuoteInfo.Quantity
QuoteInfo.ValidUntil = DateAdd("d", 30, QuoteInfo.DateCreated)  ' Default 30 days
```

**Purpose**: Job information for production management

```vba
Public Type JobData

    DueDate As Date                   ' Customer requested due date

    CustomerDueDate As Date          ' Customer delivery due date
    OrderValue As Currency           ' Job value (inherited from quote)
    DateCreated As Date              ' Job creation timestamp
    FilePath As String               ' Full path to job Excel file
    Status As String                 ' Job status tracking
    AssignedOperator As String       ' Primary operator assignment
    Operations As String             ' Manufacturing operations required
    Pictures As String               ' Technical drawing file paths
    Notes As String                  ' Additional job notes
End Type
```

**Inheritance Pattern**:
```vba
' Data inherited from QuoteData
JobInfo.QuoteNumber = QuoteInfo.QuoteNumber
JobInfo.CustomerName = QuoteInfo.CustomerName
JobInfo.ComponentDescription = QuoteInfo.ComponentDescription
JobInfo.ComponentCode = QuoteInfo.ComponentCode
JobInfo.MaterialGrade = QuoteInfo.MaterialGrade
JobInfo.Quantity = QuoteInfo.Quantity
JobInfo.OrderValue = QuoteInfo.TotalPrice
```

**Status Values**:
- **"Active"**: Job currently in production
- **"On Hold"**: Job temporarily suspended
- **"Completed"**: Job finished and ready for delivery
- **"Cancelled"**: Job cancelled by customer or internal

**Due Date Calculations**:
```vba
Select Case JobUrgency
    Case "Normal":     DueDate = StartDate + 14 days
    Case "Break Down": DueDate = StartDate + 7 days

```

## Data Validation Framework

### **Validation Functions**

**EnquiryData Validation**:
```vba
Public Function ValidateEnquiryData(ByRef EnquiryInfo As EnquiryData) As String
    Dim ValidationErrors As String

    If Trim(EnquiryInfo.CustomerName) = "" Then
        ValidationErrors = ValidationErrors & "Customer name is required." & vbCrLf
    End If

    If Trim(EnquiryInfo.ComponentDescription) = "" Then
        ValidationErrors = ValidationErrors & "Component description is required." & vbCrLf
    End If

    If EnquiryInfo.Quantity <= 0 Then
        ValidationErrors = ValidationErrors & "Quantity must be greater than zero." & vbCrLf
    End If

    ValidateEnquiryData = ValidationErrors
End Function
```

**QuoteData Validation**:
```vba
Public Function ValidateQuoteData(ByRef QuoteInfo As QuoteData) As String
    Dim ValidationErrors As String

    ' Inherit enquiry validation
    ValidationErrors = ValidateEnquiryData(QuoteInfo)  ' Cast to EnquiryData fields

    If QuoteInfo.UnitPrice <= 0 Then
        ValidationErrors = ValidationErrors & "Unit price must be greater than zero." & vbCrLf
    End If

    If QuoteInfo.ValidUntil <= Date Then
        ValidationErrors = ValidationErrors & "Quote validity date must be in the future." & vbCrLf
    End If

    ValidateQuoteData = ValidationErrors
End Function
```

## Excel File Integration

### **File Structure Mapping**

**Admin Sheet Standard Layout**:
```
Column A: Field Names (descriptive labels)
Column B: Field Values (actual data)

Row 1: Header row
Row 2+: Data fields mapped to structure members
```

**Template Integration Pattern**:
```vba
Private Sub PopulateEnquiryTemplate(ByRef wb As Workbook, ByRef EnquiryInfo As EnquiryData)
    Dim ws As Worksheet
    Set ws = wb.Worksheets("Admin")

    ws.Cells(2, 2).Value = EnquiryInfo.EnquiryNumber
    ws.Cells(3, 2).Value = EnquiryInfo.CustomerName
    ws.Cells(4, 2).Value = EnquiryInfo.ContactPerson
    ' ... continue for all fields
End Sub
```

**Data Loading Pattern**:
```vba
Public Function LoadEnquiry(ByVal FilePath As String) As EnquiryData
    Dim wb As Workbook
    Dim ws As Worksheet
    Dim EnquiryInfo As EnquiryData

    Set wb = DataOperations.SafeOpenWorkbook(FilePath)
    Set ws = wb.Worksheets("Admin")

    With EnquiryInfo
        .EnquiryNumber = ws.Cells(2, 2).Value
        .CustomerName = ws.Cells(3, 2).Value
        .ContactPerson = ws.Cells(4, 2).Value
        ' ... continue for all fields
    End With

    DataOperations.SafeCloseWorkbook wb
    LoadEnquiry = EnquiryInfo
End Function
```

## Database Integration Patterns

### **Search Database Schema** (Search.xls)

**Column Structure**:
```
Column A: RecordType (Enquiry, Quote, Job)
Column B: RecordNumber (E00001, Q00001, J00001)
Column C: CustomerName
Column D: ComponentDescription
Column E: Status
Column F: DateCreated
Column G: FilePath
Column H: Keywords
```

**Update Pattern**:
```vba
Public Sub UpdateSearchDatabase(ByRef SearchRec As SearchRecord)
    Dim SearchWB As Workbook
    Dim ws As Worksheet
    Dim LastRow As Long

    Set SearchWB = DataOperations.SafeOpenWorkbook("Search.xls")
    Set ws = SearchWB.Worksheets(1)

    LastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row + 1

    ws.Cells(LastRow, 1).Value = SearchRec.RecordType
    ws.Cells(LastRow, 2).Value = SearchRec.RecordNumber
    ws.Cells(LastRow, 3).Value = SearchRec.CustomerName
    ' ... continue for all fields

    DataOperations.SafeCloseWorkbook SearchWB
End Sub
```

## Data Flow Patterns

### **Workflow Data Transformation**

**Enquiry → Quote Data Flow**:
```vba
Public Function ConvertEnquiryToQuote(ByRef EnquiryInfo As EnquiryData, ByRef QuoteInfo As QuoteData)
    ' Copy all common fields
    QuoteInfo.EnquiryNumber = EnquiryInfo.EnquiryNumber
    QuoteInfo.CustomerName = EnquiryInfo.CustomerName
    QuoteInfo.ComponentDescription = EnquiryInfo.ComponentDescription
    QuoteInfo.ComponentCode = EnquiryInfo.ComponentCode
    QuoteInfo.MaterialGrade = EnquiryInfo.MaterialGrade
    QuoteInfo.Quantity = EnquiryInfo.Quantity

    ' Set quote-specific fields
    QuoteInfo.QuoteNumber = DataOperations.GetNextQuoteNumber()
    QuoteInfo.DateCreated = Now
    QuoteInfo.Status = "Pending"
End Function
```

**Quote → Job Data Flow**:
```vba
Public Function ConvertQuoteToJob(ByRef QuoteInfo As QuoteData, ByRef JobInfo As JobData)
    ' Copy all common fields
    JobInfo.QuoteNumber = QuoteInfo.QuoteNumber
    JobInfo.CustomerName = QuoteInfo.CustomerName
    JobInfo.ComponentDescription = QuoteInfo.ComponentDescription
    JobInfo.ComponentCode = QuoteInfo.ComponentCode
    JobInfo.MaterialGrade = QuoteInfo.MaterialGrade
    JobInfo.Quantity = QuoteInfo.Quantity
    JobInfo.OrderValue = QuoteInfo.TotalPrice

    ' Set job-specific fields
    JobInfo.JobNumber = DataOperations.GetNextJobNumber()
    JobInfo.DateCreated = Now
    JobInfo.Status = "Active"
End Function
```
